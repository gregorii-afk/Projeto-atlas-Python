
# Calculadora Python

Minha primeira calculadora feita em Python como parte do Projeto Atlas.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Proteção contra divisão por zero
- Repetição de cálculos

## Conceitos praticados

- input()
- print()
- int()
- if / elif / else
- while
- operadores matemáticos
- indentação
